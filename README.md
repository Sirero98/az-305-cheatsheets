### ¿Qué vas a encontrar?

- **18 cheatsheets temáticas** que cubren las cuatro áreas del examen: identidad y gobernanza, datos, continuidad de negocio e infraestructura.

3. Los últimos días, repasa solo las tablas y las secciones de palabras clave.

## 🇬🇧 English

### What's inside?

**Cheatsheet-style** notes to prepare for **AZ-305: Designing Microsoft Azure Infrastructure Solutions**. Each topic fits in 2 or 3 pages, goes straight to the point and is built for last-minute review: comparison tables, decision criteria and the keywords that usually show up in exam questions.

- **18 topic cheatsheets** covering the four exam areas: identity and governance, data, business continuity and infrastructure.
- **One complete PDF** with every cheatsheet merged, if you prefer a single document.
- Each cheatsheet ends with a **"question keywords → answer"** section to quickly recognise which service each scenario is asking for.

### How to use them

1. Learn the theory first on [Microsoft Learn](https://learn.microsoft.com/credentials/certifications/azure-solutions-architect/) or in whatever course you are following.
2. Use these cheatsheets to **consolidate** and compare similar services (Load Balancer vs Application Gateway vs Front Door, Service Bus vs Event Grid vs Event Hubs, and so on).
3. In the final days, review only the tables and the keyword sections.
